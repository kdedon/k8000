// z8000_decode_table -- the decode ROM as 446 distinct control words over 3617
// range records, instead of 65536 opaque hex literals. This is the file to
// read (and to review the diff of) when the decoder changes.
//
// Two record kinds, whitespace separated, '//' and '#' are comments:
//
//   ctrl <NAME> <68-bit hex>      one distinct control word
//   #    <field>=<value> ...      its fields, symbolically (see z8000_ctrl_pkg)
//   range <w0_lo> <w0_hi> <NAME>  first words w0_lo..w0_hi inclusive decode
//                                 to NAME
//
// Only fields whose value is non-zero are listed, so a line shows exactly what
// distinguishes that control word. The list is LOSSLESS: re-packing every one of them
// gives the hex bit for bit, so no field can quietly vanish from this view.
//
// Names are derived (class, ALU op, destination, source) and are for reading,
// not for addressing: a decoder change can renumber the _2/_3 suffixes.
