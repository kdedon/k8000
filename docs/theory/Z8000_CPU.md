# Z8001/Z8002 CPU (Z8003/Z8004) -- theory of operation

RTL: `rtl/k800x_cpu/`. Tests: [K800X_CPU_TESTS.md](../K800X_CPU_TESTS.md).
Results and fit: [STATUS.md](../STATUS.md).

## 1. The chip

A 16-bit CPU with sixteen 16-bit general registers, a multiplexed
address/data bus (Z-Bus) and four status lines that name every machine
cycle. The Z8001 adds a 7-bit segment number to each 16-bit address; the
Z8003/Z8004 add /ABORT so a faulting instruction can be restarted. One
core, `z8000_cpu`, builds all four.

| parameter | 0 | 1 |
|---|---|---|
| `SEGMENTED` | Z8002/Z8004: `sn` reads 0, `segt_n` ignored | Z8001/Z8003: SN pins, PC segment, SEGT/SAT |
| `VMPU` | Z8001/Z8002: `abort_n` ignored | Z8003/Z8004: /ABORT |

Pins (`z8000_cpu.sv`). AD is an in/out/enable triplet; there is no
internal tri-state.

| port | pin | note |
|---|---|---|
| `clk`, `reset_n` | -- , /RESET | board master clock; asynchronous reset |
| `clk_rise`, `clk_fall` | CLK | the CLK pin as two edge pulses (section 2) |
| `ad_in`, `ad_out`, `ad_drive` | AD15-AD0 | `ad_in` must come straight from a register |
| `sn[6:0]` | SN6-SN0 | |
| `as_n`, `ds_n`, `mreq_n`, `r_w`, `b_w`, `n_s`, `st[3:0]` | /AS /DS /MREQ R//W B//W N//S ST3-ST0 | registered outputs |
| `wait_n`, `stop_n` | /WAIT /STOP | sampled on the CLK fall |
| `busreq_n`, `busack_n`, `bus_drive` | /BUSREQ /BUSACK | `bus_drive` Low while granted: the top floats every output but /BUSACK and /MO |
| `nmi_n`, `vi_n`, `nvi_n`, `segt_n` | /NMI /VI /NVI /SEGT (/SAT) | sampled raw on the CLK rise |
| `abort_n` | /ABORT | |
| `mi_n`, `mo_n` | /MI /MO | |

## 2. Clocking and reset

Every flop runs on `clk`. The CLK pin is two one-master-clock pulses:

```
clk       _|~|_|~|_|~|_|~|_|~|_|~|_|~|_|~|_
clk_rise  _____|~~~|___________|~~~|_______    clk_en: state advances
clk_fall  _________|~~~|___________|~~~|___    fall strobes, /WAIT and /STOP samples
CLK pin   _____|~~~~~~~|_______|~~~~~~~|___    (what the pulses stand for)
```

- `clk_rise` is `clk_en`, the enable of every state flop.
- `clk_fall` moves only the strobes the AC table times from the fall
  (/AS rise, /MREQ, /DS write and I/O, both strobes' rise, SN ahead of T1)
  and takes the /WAIT and /STOP samples (`wait_q` in the bus unit,
  `stop_fq` in the top).
- The pulse spacing is free: any number of master clocks per CLK phase,
  varying from clock to clock.
- Both pulses in one master clock act as the fall, then the rise: the rise
  sees that fall's /WAIT and /STOP samples and overrides its pin changes
  (`wait_s`, `stop_s`, `as_n_f`/`ds_n_f`/`mreq_n_f`). /AS is then Low for
  one master clock.
- No clock-domain crossing exists inside the core. Asynchronous inputs
  need two-flop synchronisers at the system top.

Reset: `reset_n` asynchronously clears every flop except the register
file (`u_regfile.r`, undefined on the chip) and the refresh prescaler
(`div4_q`, `count_q`; /RESET leaves them alone). Pins in reset: AD
floated, /AS /DS /MREQ /BUSACK /MO High, ST 1111, SN 0. After release the
sequencer waits two clocks, then reads the Program Status Area (section 4.1).

### Sequencer and program ROM

`state_q`: `SEQ_RESET` -> `SEQ_PSA_REQ`/`SEQ_PSA_WAIT` (per PSA word) ->
`SEQ_FETCH` -> `SEQ_IF1` <-> `SEQ_PROG`. A word with no decode
(`ctrl.valid` 0) takes the privileged trap after its IF1.

An instruction is a **program**: a list of machine cycles. The ROM is four
lookups in series, all logic:

```
(w0, w1[3:0]) --index--> form (434)
(form, col, path) --prog--> program (206)
(program, pos) --cycle--> mc_cycle_t {kind, clocks}
(program, pos) --link---> mc_link_t  {reps, next_more, next_done, fin_more, fin_done}
```

| selector | values | set by |
|---|---|---|
| column `col_q` | NS, SS, SL | FCW SEG at the IF1; SS -> SL when an address word arrives with bit 15 set |
| path `path_q` | default, not_taken, zero | `cc_met` at the IF1's T3 edge; a multiplier's zero test (`md_take`, `md_path`) |
| position `pos_q` | 0..8 | each cycle taken; `rep_q` counts equal cycles in a row |

Cycle kinds: `F1` first word, `Fn` later word, `Fa` address word, `R`/`W`
memory, `IO`, `EPU` transfer, `AF` aborted fetch, `IA` acknowledge, `I`
internal operation of `clocks` length, `IU` internal operations the serial
unit ends. For a bus cycle `clocks` is the **tail**: clocks after T3 that
belong to the cycle. `z8000_mc_table.txt` is the same ROM as text, with
each program written out (`F1+3 . I4x16` is an IF1 with a 3-clock tail,
then sixteen 4-clock internal cycles).

The program (`prog_q`) and its entry at the position in flight, cycle and
link (`cur_q`, `link_q`), are registered, so `rep_end`, `at_last` and the
next position start at flops. The program changes as a word arrives
(`_s` looks it up as if the word on `bus_rdata` is in, and `bus_done` picks
after the ROMs), as a multiply takes its path (`_m`, on `md_take`), and at
trap or interrupt entry. The next entry is the one
in flight, or the one at the position a finished repetition count moves to
(`u_nxt_s`, `u_lnk_s`), and `rep_end` picks. This keeps `bus_done` and
`more` off the ROM inputs.

The sequencer tells the execute unit where the program is with flops:
`ex_first` (the IF1's T3 clock, the word decoded), `ex_last2`, `ex_last`
(the program's last two clocks), plus `_nx` forms one edge ahead.

### Bus unit

`state_q`: `BUS_IDLE`, `BUS_T2`, `BUS_TAW`, `BUS_T3` (named for the clock
the next edge opens), `BUS_T3CLK` (the T3 clock), `BUS_HOLD` (a tail, or
an internal operation after its T1). One requester, the sequencer; a
request is taken on the edge that ends the cycle in flight (`cyc_end`).

- `done` is combinational: T3 opens on this edge and /WAIT was High. The
  sequencer acts on it in the same clock, so a 3-clock read is followed
  by the next T1 with no gap.
- `rdata` is `ad_in`, unregistered inside the core. It feeds the decode
  and program ROMs directly, which is why `ad_in` must be a flop output.
- `tail` is read in the T3 clock; `req_len`/`req_unit` size an internal
  operation. The serial unit announces an internal cycle's end two edges
  ahead (`unit_end3`) or one (`unit_end2`).
- /BUSREQ is sampled as each T1 opens (`brq_q`); the bus is given up as
  that cycle's T3 ends (`give`) unless `lock` (TSET between its read and
  write). /BUSACK rises on the second edge that sees /BUSREQ High.

### Execute, ALU, register file

`ctrl_q` is the decode of the words as of the next edge, registered, so
the execute unit's selects start at flops. The program says when; execute places the
work on the program's clocks:

| operation | clock |
|---|---|
| byte/word register op | one ALU pass on the last clock |
| byte/word immediate | the pass as the immediate word arrives, straight off the bus |
| long op | low-word pass on the second last clock, high-word pass on the last; C and Z carried |
| rotate by 2 | one bit on each of the last two clocks; V is the two passes' V ORed |
| memory operand address | formed while the cycle is requested (port A reads pointer, base or index); latched as the cycle is taken |
| read-modify-write | the pass in the read's T3 clock, result to `wdata_q`, the write reuses the address |
| branch | PC loaded on the edge that opens the last clock |
| stack cycle | pointer on port A, the address adder steps it; written back the clock after the cycle is taken |

The register file reads combinationally from `r`; a read in a write clock
sees the old value. `nz` keeps a nonzero bit per register byte one clock
late, so a multiplier's zero test needs no read port. The FCW write has one
priority chain in `z8000_cpu.sv`: PSA load, execute's FCW load, flags from
a pass, multiply/divide flags, shift flags, multi-micro.

### Serial unit

One microword set (`uop_e`) for MULT, MULTL, DIV, DIVL and the shifts.
The destination is held as words `r_q[0..3]`, the source as `b_q`. Each
clock is one adder pass on a word, one rotate of a register pair, a latch
or a branch. It advances only on `tick` (not a wait, refresh or bus hold;
the fetch's tail after a STOP stream ticks), so it stays in step with the
program's clocks. It gives the bus unit each
internal cycle's end (`end3`, `end2`) and the sequencer the program's last
cycle (`last`).

## 4. Operation

### 4.1 Reset

```
/RESET rises -> 2 clocks -> R(0002) FCW -> [R(0004) PC seg] -> R(PC off) -> IF1
```

Three back-to-back 3-clock reads (two on a Z8002), ST 1100, system mode,
segment 0. Each word loads at its T3 edge (`fcw_we`, `pc_we`).

### 4.2 Memory read

Values just after each edge:

| edge | `state_q` before | pins |
|---|---|---|
| T1 rise | request taken (`start_txn`) | /AS Low, address, ST, R//W, B//W, N//S |
| T1 fall | `BUS_T2` | /AS High, /MREQ Low |
| T2 rise | `BUS_T2` -> `BUS_T3` | /DS Low, AD released; /ABORT sampled |
| T2 fall | `BUS_T3` | /WAIT sampled (`wait_q`); write: /DS Low |
| T3 rise | `BUS_T3` -> `BUS_T3CLK` | `done`; the word is taken from `ad_in`; Low /WAIT holds here as TW |
| T3 fall | `BUS_T3CLK` | /DS, /MREQ High |
| next rise | -> `BUS_HOLD` or the next T1 | write data released |

I/O and EPU transfers add one automatic wait (`BUS_TAW`, `taw_q` 1) and
drop /DS on T2's fall. An acknowledge adds five; /DS falls on the rise
opening the fourth. SN changes on the fall before T1 so an MMU sees it a
half clock ahead of the address.

### 4.3 Fetch, decode and a program: `ADD R1,addr`

Program text `F1 . Fa . R` (NS), `F1 . Fa+1 . R` (SS), `F1 . Fn . Fa . R`
(SL): 9, 10 and 12 clocks.

1. IF1 T3 edge (`word_if1`): the word goes to `ir0_q`; the ROM's `_s`
   lookup already used it to pick the program; PC + 2; `col_q` set.
2. `ex_first`: `ctrl_q` holds the decode. `nxt` is `Fa`, so the sequencer
   requests a fetch at the PC; the bus unit takes it on this edge.
3. `Fa` T3 edge (`word_addr`): the word goes to `ea_q`. Segmented, bit 15
   set moves to column SL and the offset word follows.
4. `R` requested: execute forms `mem_addr` from `ea_q`; `mem_take`
   latches it.
5. `R` T3 edge (`opnd_take`): the word goes to `opnd_q`. That clock is the
   program's last (`ex_last`): one ALU pass, the register and flags written
   at its end. The next IF1 is taken on the same edge.

### 4.4 Multiply: `MULT RR0,R2`

Program `F1+3 . I4x16` (path default) or `F1+3 . I8 . I4` (path zero): 70
clocks.

1. `ex_first`: `md_start`. Port A reads the destination quad; the serial
   unit loads it and starts (`LD r0,#0`, `LD count,#16`).
2. Next clock (`md_pick_q`): port B gives the source; the `nz` bits test
   it for zero; `md_take` moves the program to the zero path if so. This
   lands in the IF1's tail, where no cycle starts.
3. Sixteen frames of four microwords (`DEC`, `BR`, masked `ADD B`,
   `RRC {r0,r1}`), one per 4-clock internal cycle. The unit raises `end3`
   two edges before each cycle's end; the cycle is `IU`, so the bus unit
   ends it there and the sequencer repeats it until `last`.
4. Last clock (`md_wb`): `s_words` goes to the register pair and
   `md_flags` to the FCW.

A memory or immediate source arrives during the first frames; the first
pass that reads `b_q` holds until it is in. DIV/DIVL run the same way with
one program, ended by the unit's last cycle. MULTL repeats its frame and
add cycles while `mult_more`. A shift runs one 3-clock internal cycle per
position (`sh_start`, `sh_wb`).

### 4.5 Interrupt acknowledge

1. `smp_end`: on the T3 edge of the instruction's last machine cycle (the
   third clock of an internal operation) the interrupt unit copies the
   /VI, /NVI and SEGT levels and the NMI edge latch.
2. At the boundary `irq` replaces the next IF1 with the entry program
   (`NEXT_AF`, `irq_take`, `ext_q`). Priority: NMI, segment trap, VI, NVI.
3. The entry, nonsegmented `AF+4 . IA . W+1 . W+1 . W+4 . R . R`:

| cycle | clocks | work |
|---|---|---|
| `AF` aborted IF1 | 7 | /AS and IF1 status only, no strobes; in its tail FCW goes to system mode, R15 (R14) swap with the NSP |
| `IA` acknowledge | 10 | T1, T2, five automatic waits, T3, two tail clocks; the identifier goes to `ia_q` |
| `W` x3 (x4 segmented) | 4, (3), 4, 7 | push PC offset, (PC segment), old FCW, identifier, each at SP - 2 |
| `R` x2 (x3 segmented) | 3 each | new FCW and PC from the PSA entry |

   PSA entry offsets (`vec_q`, nonsegmented bytes): extended 04, privileged
   08, system call 0C, segment trap 10, NMI 14, NVI 18, VI 1C; a VI adds
   twice the identifier's low byte to the PC entry's address (`poff_q`).
4. A trap (privileged or undefined word, extended with EPA clear, SC)
   runs the same entry without `IA`; the identifier is the instruction word.
5. Repeat forms also sample between elements (`smp_elem`); a request
   ends the instruction there with the PC stepped back 4.

### 4.6 Refresh, STOP, bus request, abort

- Refresh: `z8000_refresh` counts CLK/4 against RATE. A pending refresh
  goes in between whole machine cycles, after an IF1, an internal cycle or
  a block element (`rf_ok_q`), three clocks, ST 0001. Up to two are owed;
  those that came due while the bus was granted or waiting go out back to
  back after any cycle (`rf_now`).
- STOP Low before an IF1 (or an EPU instruction's second word): refreshes
  run after its T3 until STOP is High again, then the fetch's tail. A
  multiply or divide's register source, taken the clock after T3, waits
  for the tail.
- /ABORT (VMPU): sampled as T2 opens and with each Low /WAIT sample
  (`abt_smp`); `abt_q` ends the instruction as that T3 ends, nothing
  written.
- HALT: a 5-clock IF1, then 3-clock internal cycles; a request seen at
  two samples in a row leaves (`halt_exit`).

## 5. Timing and resources

Machine-cycle lengths, in CLK periods:

| cycle | clocks | from |
|---|---|---|
| memory, refresh | 3 + waits | T1 T2 T3 |
| I/O, EPU transfer | 4 + waits | one automatic wait |
| acknowledge | 10 + waits | five automatic waits, two tail clocks |
| internal operation | 3 to 8 | `req_len` or the serial unit |
| tail | 0 to 4 | the program entry's `clocks` |

An instruction's length is the sum of its program's cycles; no total is
stored. Examples from the ROM:

| instruction | program | clocks |
|---|---|---|
| NOP | `F1+4` | 7 |
| ADD R,addr (NS/SS/SL) | `F1 . Fa . R` / `F1 . Fa+1 . R` / `F1 . Fn . Fa . R` | 9 / 10 / 12 |
| MULT R,R | `F1+3 . I4x16` | 70 |
| SLL R,#n | `F1+4 . Fn+3 . n x I3` | 13 + 3n |
| LDIR | `F1 . Fn+1 . n x (R+3 . W) . I4` | 11 + 9n |

`make test-cpu-cycles` checks these against the published totals from the
pins (Z8000 CPU Technical Manual, Mar81, section 6.7).

Fit (Z8001, Quartus 17.0.2, 5CSEBA6U23I7, slow corner, from
[STATUS.md](../STATUS.md), 2026-11-05; it predates the LDA and
static-shift changes):

| unit | ALMs | Fmax |
|---|---|---|
| CPU, program and decode ROMs in logic, serial unit included | 4,735 | 50.5 MHz (median of seeds 1-3; slack at 48 MHz 1.03 ns) |
| register file | 451 | 123 MHz |
| ALU | 205 | 101 MHz |
| serial unit | 658 | 72.4 MHz |

No M10K and no DSP block. Critical path: a sequencer flop, through the
register read select and the address adder, into the register file.
Structures that exist for timing: the registered decode (`ctrl_q`) with
`_nx` look-ahead inputs to execute, the parallel ROM lookups, `nz`, and
`ad_in` required from a register.

## 6. Inferred or assumed

The sources give pin timing per machine cycle and a clock total per
instruction. They do not say which clock of a program does which step.
The implementation infers:

- each program's split into cycles, tails and internal operations, and the
  clock each register write lands on;
- the serial unit's microword cadence (frames per internal cycle, setup
  and finish lengths);
- refresh details: what a REFRESH write does to the prescaler, the read
  value of bits 15:9, skipped refreshes going out back to back;
- read data taken at the T3 rise, half a clock ahead of the chip's fall;
- SN driven a half clock before T1;
- N//S Low through the acknowledge; the one-clock choice in the /BUSREQ
  release.

Where the manual leaves a result undefined, or a physical Z8001 disagrees
with it, the RTL follows captures from that chip (DECISIONS rows tagged
silicon): the PC keeps bit 15 of its last segment word (`pc_b15`; LDAR
and pushed PC segment words carry it); PSAPOFF holds bits 15:8 and PSAPSEG
bit 15 (`psap` is bits 22:8, `psapseg15`); TR* and TRT* write RH1 after
the pointer step, Z from the byte; PUSHL pushes a high-word pointer as
read; logical shifts set V on a sign change, a zero count sets C; block moves and block I/O set Z with V; COMFLG complements
H; DAB has one correction rule for both directions; RLDB/RRDB set S from
the link; short segmented LDA keeps the address word's offset byte.

Each is recorded with its evidence and a tag in
[DECISIONS.md](../DECISIONS.md) and in the spec conformance ledger of
[K800X_CPU_TESTS.md](../K800X_CPU_TESTS.md); open items are in
[STATUS.md](../STATUS.md).
