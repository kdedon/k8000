# Z8030 SCC -- theory of operation

RTL: `rtl/k8030_scc/z8030_scc.sv` (top, bus, interrupts),
`rtl/k8030_scc/z8030_scc_channel.sv` (one serial channel, instantiated twice).

## 1. The chip

The Z8030 Z-SCC is a two-channel serial controller on the multiplexed Z-Bus.
Each channel has a transmitter, a receiver with a 3-deep FIFO, a baud rate
generator (BRG), a digital PLL (DPLL) and NRZ/NRZI/FM coding. Modes built:
async, SDLC, SDLC Loop, monosync, bisync, external sync. Interrupts go
through /INT, /INTACK and the IEI/IEO daisy chain.

No parameters. Vector index `[0]` is channel A, `[1]` channel B.

| pin | port | notes |
|---|---|---|
| AD7:0 | `ad_in`, `ad_out`, `ad_drive` | in/out/enable triplet |
| /AS, /DS, R/W | `as_n`, `ds_n`, `r_w` | |
| /CS0, CS1 | `cs0_n`, `cs1` | |
| /INTACK, IEI, IEO, /INT | `intack_n`, `iei`, `ieo`, `int_n` | /INT open-drain |
| PCLK | `pclk_rise` | rising-edge pulse |
| RxD, TxD | `rxd[1:0]`, `txd[1:0]` | |
| /RTxC | `rxc_rise`, `rxc_fall` | edge pulse pair per channel |
| /TRxC | `trxc_rise`, `trxc_fall`, `trxc_out`, `trxc_drive` | output when WR11 D2 |
| /SYNC | `sync_in`, `sync_out`, `sync_drive` | driven in monosync and bisync |
| /CTS, /DCD | `cts_n`, `dcd_n` | |
| /RTS, /DTR | `rts_n`, `dtr_n` | WR5 D1, D7 |

/W//REQ A and B have no port. The chip has no reset pin and the module no
reset port.

## 2. Clocking and reset

One master clock `clk` runs every flop. Nothing is a derived clock.

| chip signal | how the RTL sees it |
|---|---|
| PCLK | `pclk_rise`, one master clock wide; may fire on consecutive master clocks |
| /RTxC, /TRxC | rise/fall pulses rebuild a level (`rxc_in`, `trxc_in`); the level is compared with its value at the previous PCLK rise (`prev_rtxc`, `prev_trxc`), so an edge is seen at the next PCLK rise |
| /AS, /DS, /INTACK | oversampled by `clk`; edges are combinational against the registered previous level (`as_fall = as_q & ~as_n`, ...) |
| RxD, /DCD, /CTS, /SYNC | read as they stand at the PCLK rise |

Two time bases follow from that:

- Every master clock: strobe edge detect, the address latch, the /DS-fall
  capture, the /INT latch (`int_latch`, clocked by the /AS rise), the reset
  counter, and the combinational outputs (`int_n`, `ieo`, the AD release).
- PCLK rise only: register read and write, the acknowledge, and all serial
  logic. A strobe edge that falls between PCLK rises waits in a pending flag
  (`pend_as_fall`, `pend_as_rise`, `pend_ds_fall`, `pend_ds_rise`,
  `pend_intack_rise`); one in the same master clock as a PCLK rise is
  serviced in that clock, ahead of the serial step.

There are no synchronisers inside the module. A system top puts 2-flop
synchronisers on RxD, /RTxC, /TRxC, /SYNC, /DCD, /CTS and the bus strobes.

Reset. /AS and /DS Low together (`hw_reset`) across two PCLK rises
(`res_cnt`) gives `pin_reset`. The width qualification keeps a bus
turnaround overlap from wiping the chip (Z8030 data sheet p.648 rows
37-39). WR9 D7:D6 = 11 is the same reset from software (`wr9_hw`) except
that it keeps Shift Right; 10 and 01 reset channel A or B alone. No flop
has a power-up value: a board holds both strobes Low at power-up.

| register | hardware reset | channel reset |
|---|---|---|
| WR0 | 00 | 00 |
| WR1 | &= 24 | &= 24 |
| WR3 | D0 clear | D0 clear |
| WR4 | D2 set | D2 set |
| WR5 | &= 61 | &= 61 |
| WR9 | &= 03 | kept |
| WR10 | 00 | &= 60 |
| WR11 | 08 | kept |
| WR14 | D7:D6 kept, 20 | &= C3, D5 set |
| WR15 | F8 | F8 |
| WR2, WR12, WR13 | kept | kept |
| IUS, /INT latch | clear | kept |
| BRG | stopped, count 0, loads on its first clock | keeps running |

       AD out <---- rd_mux <------+<--- rd_data ----| channel  | | channel  |

### Top (`z8030_scc.sv`)

| block | state | function |
|---|---|---|
| strobe capture | `as_q`, `ds_q`, `intack_q`, `pend_*` | edge detect; carries edges to the next PCLK rise |
| /AS latch | `as_ad`, `as_cs_n`, `as_intack_n` | transparent while /AS is Low, frozen at the rise; the `*_now` wires give the live value in the same clock |
| /DS latch | `ds_ad`, `ds_rw`, `ds_cs1`, `ds_iei`, `ds_spent` | taken at `ds_strobe`: a /DS fall with /AS High, once per /AS |
| decode | `bus_active`, `bus_ch`, `bus_reg` | at the PCLK rise that sees the /AS rise: selected if /CS0 Low and /INTACK High; register = AD4:1; channel on AD5 (Shift Left) or AD0 (`shift_right`) |
| read mux | `ad_out_q`, `ad_drive_q` | RR2 and RR3 here, the rest from the channel's `rd_data` |
| chip registers | `int_vector` (WR2), `wr9`, `shift_right`, `ius` (one bit per level) | WR2 and WR9 are written from either channel; `wr9` keeps D5:D0 (D7:D6 are commands) |
| interrupt priority | combinational: `lvl_req`, `lvl`, `src`, `ius_top` | see section 4 |
| /INT latch | `int_latch` | `int_pending & iei` at every /AS rise |

### Channel (`z8030_scc_channel.sv`)

One `always_comb` computes every `n_*` next value in program order and one
`always_ff` commits them. The order is the behaviour: bus side first
(reset, register write, WR0 command, RR8 pop), then, under `pclk_rise`, one
step of ext/status, BRG, DPLL, clock mux, transmitter, coder, receiver,
FIFO. Each step sees what the earlier steps of the same clock did.

| block | key state | notes |
|---|---|---|
| registers | `wr[1..15]` (not 2, 8, 9), `tx_buf`, `tx_buf_empty` | WR0 is commands only; WR8 is `tx_buf` |
| ext/status | `dcd_sync1`, `cts_sync1`, `sync_pin`, `ext_ip`, `ext_latch_closed`, `dcd_latch`, `cts_latch`, `break_latch`, `underrun_latch`, `hunt_latch` | a WR15-enabled transition sets `ext_ip` and closes the latch over RR0; Reset Ext/Status reopens it |
| BRG | `baud_counter` (16 bits), `brg_out`, `brg_reload`, `brg_sync` | counts down on PCLK rises (WR14 D1) or /RTxC rises |
| DPLL | `dp_cnt` (5 bits), `dp_adj`, `dp_next`, `dp_seen`, `dp_search`, `dp_fm`, `dp_brg`, `dp_miss1/2`, `dp_rxo`, `dp_txo` | 32 counts per bit cell |
| clock mux | combinational: `tx_edge`, `tx_mid`, `rx_edge`, `rx_half`; `trxc_out_lvl` | WR11 D4:D3 transmit, D6:D5 receive, D1:D0 /TRxC output |
| async Tx | `tx_state` (0 idle, 1 start, 2 data, 3 parity, 4 stop, 5 pending), `tx_shift`, `tx_bit_count`, `tx_sub_count`, `tx_stop_bit`, `tx_all_sent`, `tx_break`, `rts_hold` | |
| sync Tx | `sd_tx_sr`, `sd_tx_n`, `sd_tx_kind` (0 flag/idle, 1 data, 2 CRC), `sd_tx_ones`, `sd_tx_crc`, `sd_tx_pipe`, `sd_tx_crc_on` | shared by SDLC and byte sync |
| SDLC Loop | `lp_on`, `lp_send`, `lp_poll`, `lp_bit`, `lp_conv`, `lp_drain` | |
| coding | `tx_line`, `tx_raw`, `rx_prev` | WR10 D6:D5; active in any x1 mode |
| async Rx | `rx_state` (0 idle, 1 start, 2 data, 3 parity, 4 stop), `rx_shift`, `rx_shift_err`, `rx_sub_count`, `rx_bit_count`, `rx_break` | |
| sync Rx | `sd_hunt`, `sd_in_frame`, `sd_rx_raw`, `sd_rx_ones`, `sd_rx_hist` (D31:D14), `sd_rx_nb`, `sd_rx_cnt`, `sd_rx_crc`, `sd_residue`, `sd_rx_pend`, `sd_crc_on`, `sd_strip_prev`, `sd_sync_out` | shared by SDLC and byte sync |
| Rx FIFO | `rx_fifo_data[3]`, `rx_fifo_err[3]`, `rx_fifo_len`, `rx_err_sticky`, `rx_lock` | error byte: D0 parity, D1 overrun, D2 framing or CRC, D3 End of Frame |
| interrupt sources | `tx_ip`, `ext_ip`, `rx_int_next_char`, `rx_int_forced` | `rr3_ip`, `int_req` to the top |

## 4. Operation

### Register access

```
 /AS  --\____/---------------------
 AD   --<addr>---<write data / read data>--
 /DS  ------------\__________/-----
           |  |    |   |      |
           a  b    c   d      e
```

| | event | action |
|---|---|---|
| a | /AS Low | `as_ad`, `as_cs_n`, `as_intack_n` follow the pins; `ad_drive_q` drops at the next PCLK rise |
| b | /AS rise | latch freezes; `int_latch` updates; at the PCLK rise, `bus_active`, `bus_ch`, `bus_reg` |
| c | /DS fall, /AS High | `ds_strobe`: `ds_ad`, `ds_rw`, `ds_cs1`, `ds_iei` taken |
| d | PCLK rise | `bus_cycle` if selected and CS1 was High at c. Read: `ad_out_q <= rd_mux`, drive on. Write: `ch_wr` to the channel(s); WR2, WR0 Reset Highest IUS and WR0B Shift Right/Left in the top |
| e | /DS rise | `ad_drive` drops combinationally; `ds_spent` blocks any further /DS until the next /AS |

Read data therefore appears up to one PCLK after the /DS fall and floats at
the /DS rise with no PCLK term.

Reads: RR0, RR1, RR8, RR10, RR12, RR13, RR15 from the channel; RR2
(channel A the stored vector, channel B the vector with status) and RR3
(channel A only) from the top; anything else reads 0. An RR8 read pops the
FIFO; under WR1 D3 a character with a special condition stays at the exit
(`rx_lock`) until Error Reset.

WR0 commands (D5:D3) and CRC resets (D7:D6) execute in the write's own PCLK
step.

### Async transmit

1. A WR8 write loads `tx_buf` and clears `tx_buf_empty` and `tx_ip`.
2. On the next PCLK rise with the transmitter idle and enabled (WR5 D3, and
   /CTS Low under Auto Enables), TBR moves to `tx_shift`; `tx_state` goes to
   5 (pending), `tx_ip` sets, `tx_all_sent` clears.
3. Each `tx_edge` advances the FSM. `tx_sub_count` counts the clock mode
   `cm` (x1, x16, x32, x64 from WR4 D7:D6) per bit: start, 5 to 8 data bits
   LSB first, parity, stop.
4. Stop: 1, 2, or 1.5 bits (a full bit then `cm/2` clocks; x1 sends 1). At
   the end, a waiting TBR character starts on the same edge; an empty TBR
   returns to idle, sets `tx_all_sent` and Tx Underrun/EOM.
5. `txd_q` is registered from `tx_state`. Send Break (`tx_break`, taken at a
   bit-cell edge) forces TxD Low over the shifting transmitter.

Dropping RTS with Auto Enables sets `rts_hold`, which keeps /RTS Low until
TSR and TBR are empty.

### Async receive

1. Idle (`rx_state` 0): RxD Low at an `rx_edge` starts a character. x1 goes
   straight to data.
2. Start (x16/32/64): High at mid-bit (`rx_mid = (cm+1)/2`) is a glitch and
   returns to idle.
3. Data, parity, stop: each bit is sampled at `rx_mid`. Parity error sets
   error D0, a Low stop bit D2. One stop bit is checked whatever WR4 says.
4. At the end of the stop bit the character is pushed (`rx_push`). Unused
   high bits read 1 (`rx_fill`); a parity bit that fits lands above the
   data.
5. A null with a framing error is a break: not pushed, `rx_break` sets
   (ext/status). When RxD returns High one null is pushed.
6. Push into a full FIFO overwrites the newest entry and tags it overrun.
   Parity and overrun of the exit entry accumulate in `rx_err_sticky`
   (RR1) until Error Reset.

A disabled receiver (WR3 D0 clear, or /DCD High under Auto Enables) is held
idle.

### BRG and clock mux

`baud_counter` counts down. At zero the output flip-flop `brg_out` toggles
(`brg_edge` on the rise, `brg_fall` on the fall) and the next clock
(`brg_reload`) loads WR13:WR12, so each half is `TC + 2` clocks and a new
time constant takes effect at the next half. The enable is synchronised
to the BRG clock (`brg_sync`): the first clock after WR14 D0 is set does
not count. Clearing WR14 D0 holds the count and output level; a hardware
reset sets the output High, clears the count and leaves the load to the
first counting clock.

| WR11 | source | cell start (`tx_edge` / `rx_edge`) | half (`tx_mid` / `rx_half`) |
|---|---|---|---|
| 00 | /RTxC | rise | fall |
| 01 | /TRxC | rise | fall |
| 10 | BRG | `brg_edge` | `brg_fall` |
| 11 | DPLL | Tx: `dp_txo` rise (fall in FM); Rx: `dp_rxo` fall | the other edge |

### DPLL

`dp_cnt` steps on rises of its source (BRG or /RTxC, `dp_brg`). In search
it waits at 16; the first RxD edge releases it. Outputs:

| mode | receive output High | transmit output High |
|---|---|---|
| NRZI | counts 16-31 | counts 16-31 |
| FM | 4-11, 20-27 | 8-15, 24-31 |

The first RxD edge of a cycle (in FM, inside the window) is placed in half
counts (`d_h`) against the cell boundary (half counts 31/32) and sets
`dp_next`: on the boundary 0; after it 1 (count 5 held one clock); before
it 2 (count 5 skipped). The correction is adopted at the end of the cycle and
applied in the next. FM with no edge in the window sets One Clock Missing;
two in a row set Two Clocks Missing and return to search. The outputs for a
counting clock come from `dp_srx`/`dp_stx`, computed from registers, which
keeps the DPLL off the path into the receiver.

### SDLC

Transmit, per `tx_edge`:

1. At a character boundary (`sd_tx_n == 0`): buffered data if any
   (`sd_tx_kind` 1); else, with the Tx Underrun/EOM latch reset, the
   inverted CRC (kind 2) or an abort/flag, and the latch sets; else the idle
   flag (WR7) or marks.
2. One bit leaves `sd_tx_sr`. After five 1s of data or CRC a 0 is inserted
   and the shift register holds (`sd_tx_ones`). Data bits step `sd_tx_crc`
   when WR5 D0 is set (CRC-CCITT, or CRC-16 with WR5 D2).
3. The bit enters `sd_tx_pipe`; TxD is five clocks behind.

Receive, per `rx_edge`:

1. `sd_rx_raw` holds the last 8 line bits; `sd_rx_ones` counts 1s. Seven 1s
   is an abort: Break/Abort sets, the receiver enters Hunt.
2. `sd_rx_raw == WR7` is a flag: it ends Hunt, opens a frame, presets the
   CRC.
3. In a frame, bits other than deleted 0s shift into `sd_rx_hist`. The CRC
   checker runs 8 bits behind, the character assembler 10 bits behind
   (`sd_rx_nb`). Each `rx_bits` bits a snapshot (`sd_snap`) is pushed.
4. Address search (WR3 D2): the first character must match WR6 (high nibble
   only with WR3 D1) or FF, else the frame is dropped.
5. A closing flag pushes the partial character with End of Frame, the CRC
   compare (remainder F0B8) and the residue code in `sd_residue`.

SDLC Loop: off loop TxD is RxD; with Go Active On Poll an EOP (seven 1s)
puts the channel on loop (`lp_on`), adding the one-bit delay `lp_bit`. On
loop, a flag then an EOP takes the loop (`lp_send`): one 0, the parked flag,
then data. A flag leaving without Go Active On Poll hands TxD back five bits
later (`lp_drain`).

Byte sync (monosync, bisync, external sync) uses the same shift register,
CRC and history: the transmitter idles the sync pattern from WR6/WR7 with no
zero insertion; the receiver hunts with `sync_match()` or the /SYNC pin,
then loads a character every `rx_bits` (+ parity) bits, with the CRC checker
16 bits behind.

### Interrupts and the daisy chain

Each channel raises `int_req = {Rx fires, Rx is special, Tx, Ext/Status}`,
each gated by its WR1 enable. The top maps them to eight sources:

| code | source | level |
|---|---|---|
| 7, 6 | A receive special, A receive | 5 |
| 4 | A transmit | 4 |
| 5 | A ext/status | 3 |
| 3, 2 | B receive special, B receive | 2 |
| 0 | B transmit | 1 |
| 1 | B ext/status | 0 |

`lvl_req` holds one request per level and `lvl` the highest; `src` is its
code. `int_pending = MIE & request & no IUS bit at or above lvl`.

```
 request ---> int_pending --(/AS rise, & IEI)--> int_latch ---> /INT

 acknowledge:
 /INTACK --\________________________/--
 /AS     ----\__/----------------------   as_intack_n latched Low; int_latch updated
 IEO     -------\________________...      Low if int_latch (chain settles)
 /DS     ----------------\______/------   IEI sampled at the fall
 AD      ----------------<vector>------   from the PCLK rise after the fall
```

1. A request reaches /INT only at an /AS rise, selected or not, and only
   with IEI High.
2. In an acknowledge (`as_intack_n` Low) a chip with `int_latch` set pulls
   IEO Low. `ieo = ~DLC & iei & (ius == 0) & ~(acknowledge & int_latch)`.
3. At the PCLK rise that sees the /DS fall, `ack` needs IEI High at that
   fall, `int_latch` and `int_pending`. It sets the level's bit in
   `ius` and, unless NV (WR9 D1), drives the vector: `int_vector`, or
   with VIS (WR9 D0) `mod_vec`, the source code in V3:V1 or bit-reversed in
   V6:V4 (Status High, WR9 D4).
4. The same step re-latches /INT from what is still pending above the new
   IUS (`pend_ack`). A request that arose after the acknowledge's /AS never
   takes that acknowledge.
5. AD floats at the /DS rise or the /INTACK rise.
6. WR0 Reset Highest IUS clears the top bit of `ius` (`ius_top`),
   releasing IEO.

## 5. Timing and resources

External timing is in PCLK and strobe units:

| event | latency in the RTL |
|---|---|
| read data, write effect, acknowledge vector | the PCLK rise at or after the /DS fall |
| AD float | combinational from /DS High |
| /INT | the first /AS rise after the PCLK rise that raised the condition |
| /DCD, /CTS transition to ext/status | one PCLK rise |
| /RTxC, /TRxC edge to its effect | the next PCLK rise, so the serial clocks must be slower than PCLK |
| reset | second PCLK rise with /AS and /DS both Low |
| BRG output | one cycle per `2 x (TC + 2)` source clocks |
| SDLC TxD | five transmit clocks behind the shift register |

Fit (Cyclone V, 48 MHz target, Quartus 17.0.2; see
[STATUS.md](../STATUS.md)): 1,990 ALMs, 1,019 registers, no block memory,
no DSP; Fmax 51.6 MHz, setup slack 1.46 ns. The fit predates the latest
acknowledge change.

Critical path: `as_q` (or the /AS pin flop) through the transparent address
latch, decode, write enable and the channel's single next-state chain into
`hunt_latch`. The chain is long because one PCLK step runs ext/status, BRG,
DPLL, both clock muxes, transmitter and receiver in sequence; the BRG
compares and the DPLL's next outputs are taken from registers to shorten it.

## 6. Inferences and assumptions

The full tables are the SCC rows of [DECISIONS.md](../DECISIONS.md) and the
spec conformance ledger in [K8030_SCC_TESTS.md](../K8030_SCC_TESTS.md).
In summary:

- Open in the sources: /DCD and /CTS synchroniser depth (one PCLK taken);
  the reset width between 30 and 250 ns (two PCLK rises taken); /INT
  latency against the published minimum.
- Inferred: one access per /AS; the SDLC checker and assembler delays (8
  and 10 bits); byte-sync load moment; which clock edge does what in FM;
  DPLL edge placement, first-edge-wins and the cycle a correction applies
  in; SDLC Loop edge placement and hand-back; the 1.5 stop bit count.
- Not built: /W//REQ, the DTR/REQ function (WR14 D2 is stored only), Zero
  Count (WR15 D1 stored, RR0 D1 reads 0), parity in SDLC, SDLC Loop in FM,
  the sync-mode loop (WR10 D1 outside SDLC), /SYNC as an output in SDLC and
  as an input in async, the 4-5 PCLK reset stretch. Later-part features
  (WR7', status FIFO, deeper FIFOs) are not on the NMOS Z8030.
- WR14 D4 resets to 0 (the bit text) though the reset table prints 1.
