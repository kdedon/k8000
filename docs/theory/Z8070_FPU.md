# Z8070 FPU -- theory of operation

RTL: `rtl/k8070_fpu/`. Tests: [K8070_FPU_TESTS.md](../K8070_FPU_TESTS.md).
Source: Z8070 Preliminary Product Specification (Zilog 1985 Data Book,
printed pp.531-558), cited below as "spec". It has no pinout, no AC table
and no word-2 encodings; where it is silent the choice is assumed and the
vectors carry it (section 6).

## 1. The chip

An Extended Processing Unit on the Z-Bus. It watches the CPU fetch
extended instructions, takes those addressed to its ID, moves operands
and results in the data cycles the CPU runs for it, and computes IEEE
single, double and extended arithmetic on eight 80-bit registers. /BSY
holds the CPU (STOP) while it cannot accept more; /INT reports traps.

Pins of `z8070_fpu` (spec pp.542-545: common signals plus the Z8000
interface):

| port | pin | notes |
|---|---|---|
| `clk` | -- | board master clock |
| `clki_rise`, `clki_fall` | CLK.I | edge pulses, one master clock each |
| `clkd_rise` | CLK.D | rise pulse |
| `reset_n` | /RESET | level |
| `ad_in`, `ad_out`, `ad_drive` | AD15-AD0 | in/out/enable triplet |
| `as_n`, `ds_n`, `r_w`, `n_s`, `st[3:0]`, `sn[6:0]` | Z-Bus | snooped |
| `b_w` | B//W | unread: every transfer is a word |
| `busack_n` | /BUSACK | Low: another master's cycle, ignored |
| `abort_n` | /ABORT | level: drops the executing and queued instruction |
| `bsy_n` | /BSY | to the CPU's STOP (and /WAIT on EPU data cycles) |
| `int_n`, `iei`, `ieo` | /INT, IEI, IEO | `int_n` open drain at the pad |
| `id[1:0]` | ID1-ID0 | copied to SC.ID during reset |
| `opt[1:0]` | OPT1-OPT0 | unread: only the Z8000 interface (11) is built |

No parameters.

## 2. Clocking and reset

Every flop runs on `clk`. There is no second clock domain and no CDC.

| chip signal | seen as | used for |
|---|---|---|
| CLK.I rise | `clki_rise` | start of the queued instruction (`promote`); the FOP read-back wait (`fset_q`) |
| CLK.I fall | `clki_fall` | AD sampled into `ds_data_q` while /DS is Low (spec p.546: data taken "before the falling edge of the clock in the middle of T3") |
| CLK.D rise | `clkd_rise` | one microword of the Data Processor (`step`) |
| /AS, /DS | levels, edges against `as_q`/`ds_q` | address follows while /AS Low; status, R/W, N/S latched at `as_rise`; the cycle is acted on at `ds_rise` |

CLK.I and CLK.D may pulse in any master clocks, including the same one;
the benches run 1 to 4 master clocks per phase. Two requirements follow
from the registered decode (section 4.1): the CLK.I fall inside /DS comes
at least one master clock before the /DS rise, and a Data Processor
`start` never shares a master clock with `done`.

/RESET is a level tested every master clock: SC, USER, FFLAGS, PC1, PC2
and the sequencer state clear; SC.ID takes the ID pins; pins are idle
(`ad_drive` 0, /BSY and /INT High, IEO = IEI). The register file is a RAM
and is not cleared; it powers up 0 (spec p.542 names only USER, FFLAGS
and SC).

### Interface Processor (`z8070_ip.sv`)

| state | holds |
|---|---|
| `cyc_addr_q`, `cyc_st_q`, `cyc_write_q`, `cyc_ns_q`, `cyc_open_q` | the bus cycle: {SN, AD} at the /AS rise, status, direction, N/S, and the /AS-rise to /DS-rise window |
| `ds_data_q` | the cycle's data word |
| `w1_q`, `tpl_q` | word 1 bits 7:4 and the template, from IF1 to word 2 (a held IF1's from its capture) |
| `mn_q`, `dir_q`, `fmt_q`, `ra_q`, `rb_q`, `sel_q`, `words_q`, `list_q` | the plan of the executing instruction |
| `p_mn`, `p_dir`, `p_fmt`, `p_ra`, `p_rb`, `p_sf`, `p_lst`, `p_fcw`, `p_dp`, `p_ns` | the queued instruction's plan |
| `p_kind`, `p_prec`, `p_rm`, `p_out` | the queued operation's start fields |
| `hold_q`, `hold_pc_q` | a held IF1 and its address |
| `hold_w2_q`, `rp_q`, `rp_rdy_q`, `op_ld_q`, `done_q` | a kept word 2, whether one is kept and the start fields took its decode, whether they followed the decode last clock, done last clock |
| `capk_q`, `capk_n_q`, `capk_v_q` | a queued operand word kept until row 10 holds the running operation's bus operand |
| `state_q` (`IP_IDLE`, `IP_WORD2`, `IP_OPERAND`, `IP_DPWAIT`, `IP_RESULT`) | executing instruction |
| `pend_q` (`PQ_NONE`, `PQ_W2`, `PQ_CAPT`, `PQ_READY`) | queued instruction |
| `cnt_q` | operand/result word index |
| `buf_q[0:4]` | transfer buffer, first word in 0 |
| `sc_q`, `user_q`, `fflags_q`, `pc1_q`, `pc2_q` | control registers |
| `kind_q`, `prec_q`, `rm_q`, `out_q`, `armw_q`, `armi_q` | the executing operation's start fields, and whether a word 2 or the last operand word starts it, decided a clock ahead |

One `always_comb` forms the next state from the events of the master
clock (`launch`, `p_load`, `promote`, `capture`, `fold`, `raise`, ...);
the register blocks commit them.

### Decode (`z8070_dec.sv`, `gen/z8070_enc_pkg.sv`)

Combinational, two lookups:

| input | output |
|---|---|
| IF1 first byte, bits 3:0 | `if1_epa` (an extended instruction), `if1_ok` (has a template), `if1_tpl`, `if1_id` |
| template, word 1 bits 7:4, word 2 | `plan_ok`, mnemonic, Fd, Fs, format, rounding, select, list byte, direction, word count |

Templates (Jan83 Z8000 CPU Technical Manual): 0F/4F memory, 8F CPU
register, 8E FCW or internal; direction in bits 3:2, ID in bits 1:0. The
operation code is {word 2 bits 15:14, 7:4}, looked up by `enc_lookup` in
the hand-maintained table; n-1 is word 2 bits 3:0. The operation codes
themselves are assumed (section 6).

The decoder reads `ds_data_d`, the data latch's next value, and its
outputs are registered (`pl_*`). The unregistered `pl_*_u` values address
the register file and form the registered start fields, so a start at the
/DS rise is a strobe edge and a flop.

### Register file (`f_mem` in `z8070_dp.sv`)

16 x 80 MLAB, one write port, one registered read port: rows 0-7 F0-F7,
8 FOP1, 9 FOP2, 10 a bus operand kept for FOP1 once a queued
instruction needs the buffer. Format {sign, exponent 15, significand 64}.
The Interface Processor drives both ports; `f_raddr` is set a master
clock ahead of use (`dp_opnd_rd` says when the running microword samples
the operand bus). `dp_opnd` muxes the read port, the bus operand `bus_x`
(single and double rebiased by one adder, `b_sum`) and, for the write
port, the result.

### Data Processor (`z8070_dp.sv`)

| state | role |
|---|---|
| `run_q`, `upc_q`, `kind_q`, `prec_q`, `rm_q`, `out_q` | microprogram counter and the operation, latched while idle |
| `a_*`, `b_*` | operands: sign, 17-bit biased exponent, 64-bit significand, class |
| `s_sign`, `s_exp`, `s_sig[67:0]` | working value: {carry, 64 bits, guard, round, sticky} |
| `x_q`, `qm_q` (66 bits) | 3M in a multiply; positive and negative quotient digits in a divide |
| `cnt_q`, `d_q`, `dnrm_amt_q` | step count / shift count, exponent difference, denormalize amount |
| `fl_q`, `rsn_q`, `rup_q`, `cmp_q` | flags, invalid reason, rounded-up, compare code |
| `res_q` and its flag fields | result latch, loaded at PACK |

Shared units, each used once per clock, operands selected by the action:

| unit | signal | width |
|---|---|---|
| significand adder | `ad_x`, `ad_y`, `ad_sub`, `ad_ci` -> `ad_sum` | 69 |
| exponent adder | `ex_x`, `ex_y`, `ex_sub` -> `ex_sum` | 17 |
| barrel shifter, right with sticky or left | `sh_in`, `sh_amt`, `sh_left` -> `sh_out` | 68 |
| leading-zero counter | `lz_in` -> `lz_out` | 66 |
| special-operand select | `xs_*` | one select for every operation |
| SRT digit table | `srt_digit(S[67:62], D[62:60])` | radix 4, digits -2..2 |

No multiplier block and no M10K: products and quotients are built on the
adder, two bits a clock.

### Microprogram (`z8070_dp_ucode.txt` -> `gen/z8070_dp_rom.sv`)

63 words, 55 actions, 23 dispatch entries, as a ROM in logic. A word is
15 bits:

| field | bits | meaning |
|---|---|---|
| `act` | 6 | the clock's datapath action (`DA_*`) |
| `seq` | 2 | `NEXT`, `JMP tgt`, `JCOND tgt` (the action's own test, `cond`), `RET` (to the body of the latched operation) |
| `tgt` | 6 | jump target |
| `fin` | 1 | the operation's last clock |

Each operation has an entry (usually the shared unpack) and a body; `RET`
at the end of the unpack goes to `body(kind_q)`. While idle the Data
Processor latches the next operation and loads `upc_q` with its `entry`
every clock but the start's, so a CLK.D rise in the start's master clock
runs the first word from the ROM at `upc_q`.

Shared routines:

```
UNP_A UNP_AR UNP_B UNP_BR      unpack: read, classify, renormalize A then B
   |
   +-> <op>_SP ...             special-operand select, then the body
          |
          v
ADD_CY -> ADD_LZ -> ADD_NM -> ADD_DN -> ADD_RD -> ADD_RG   carry, LZC, normalize,
          |                                         |      denormalize, round, range
          v (zero sum / remainder)                  v
        TAIL (PACK: result latch)  ->  TAIL_WB (WB, fin)
```

## 4. Operation

### 4.1 The CPU-FPU protocol

The CPU fetches and addresses; the FPU only watches, then sources or
sinks words in the cycles the CPU runs (spec p.545).

| cycle (status at /AS rise) | at the /DS rise |
|---|---|
| 1101 IF1, extended first byte | other ID: Invalid EPU ID if its SC.EPUIDS bit is set, else ignored. Own ID: no template is Invalid opcode; else keep word 1, template, address -> PC1, go to `IP_WORD2`; if busy, queue it (PC2, `PQ_W2`); with `PQ_READY`, hold it (`hold_q`) |
| 1100 while in `IP_WORD2` / `PQ_W2` / with an IF1 held | word 2 through the table: no row or an impossible word count is Invalid opcode, raised when the instruction would run (assumed: in program order, PC1 its address): executing, at once; queued (`p_inv`) or held, at its `promote`. Else queued: `p_load`. Executing: `launch` (`w2_now`), unless it starts the Data Processor and the start registers did not follow its decode the clock before (`op_ld_q`) or done was last clock (`done_q`); then kept in `hold_w2_q` (`rp_q`, the decoder reads it from then on) and taken the clock after they do (`rp_go`). Held: kept with the IF1 |
| 1010, 1011 memory, 1110 CPU-EPU | one operand or result word, first word first |
| anything else, or /BUSACK Low | unseen |

After `launch` the instruction runs one of three ways:

| direction | flow |
|---|---|
| in | `IP_OPERAND`: words into `buf_q`; the last one writes a control register (FLDCTL), the compare flags (EPU<-FCW), or starts the Data Processor |
| out | FLDCTL/FLDCTLB go straight to `IP_RESULT` and source their register; others start the Data Processor (`IP_DPWAIT`), then source `dp_res` in `IP_RESULT` |
| none | flag, trap and mode lists change FFLAGS or USER in that master clock (`list_go`); the rest start the Data Processor |

Example, a memory-operand FADD (double):

```
bus:   IF1    word2   data0  data1  data2  data3            IF1 (next)
/DS    _-     _-      _-     _-     _-     _-
state  IDLE   WORD2   OPERAND ................ DPWAIT ....... IDLE
                                              ^dp_start      ^dp_done (fold)
/BSY   ---------------------------------------______________--   (No Overlap)
```

`dp_start` rises in the master clock of the last word's /DS rise
(`armi_q` was set a clock earlier), or of a word 2 taken that starts it
(`armw_q`, from the unregistered decode). The
Interface Processor adds no clock of its own (assumed: none is
published).

Drive windows (`drive`): a store word to memory from the /AS rise to the
/DS rise; a word to the CPU (1110 read) while /DS is Low; never with
/BUSACK Low. Byte forms put the byte on AD7-0 and 00 above. Result words
are formed field by field from `dp_res` (`img`, `out_word`): single and
double get their exponent rebiased and their fraction cut here.

A store word requested while the result is not ready (`IP_DPWAIT`) is
lost but counted, so the word index stays in step with the CPU. STOP
prevents it: the CPU refreshes after the T3 of IF1 or word 2 while STOP
is Low; the board also takes /BSY to /WAIT.

### 4.2 Interface Processor and Data Processor

The hand-over is five signals wide and adds no clock:

```
IP                                            DP
kind, prec, rm, out (next values)  --> latched while idle, with upc_q <- entry
dp_start (1 master clock)          --> run; the first microword if CLK.D rises
dp_opnd  <-- f_rdata | bus_x           sampled in UNPA / UNPB / ILD
             (dp_opnd_src: 0 destination, 1 source; dp_opnd_rd: sampling now;
              dp_opnd_nxt: between the unpacks, dp_opnd_src naming the second)
dp_done  <-- High in the master clock of the last CLK.D rise
dp_res, dp_flags, dp_reason, dp_rup, dp_cmp <-- result latch, loaded one clock before done
```

At `fold` (`IP_DPWAIT` and `dp_done`), in that master clock:

| step | when | condition |
|---|---|---|
| F[Fd] <- result (`wb_now`) | done clock | not a compare; not outbound, except FREMSTEP |
| FFLAGS: flags to 15:8, ORed into 7:0; compare code, R, reason (`apply`) | done clock | not FLDNF |
| trap request, SC.IR 00 (`trap`) | done clock | a flag whose USER trap enable is set |
| FOP1 <- input operand (`fop_q`) | next clock | any flag set |
| FOP2 <- default result (`fop2_now`), from the result latch, not the operand bus | the clock after, unless row 10 is written | any flag set |
| row 10 <- the running operation's bus operand (`stg_now`) | the clock after a queued IF1, or after a promote that queues a held one | not in a done clock or the one after |

The writes share the RAM's one write port, hence the sequence. The read
register loads in the done clock unless FOP1 needs it held. An
FLDCTL of FOP1 or FOP2 right after a flagged operation holds /BSY for
three CLK.I rises (`fset_q`, `fop_wait`) until the rows are written and
read back.

### 4.3 Queue and /BSY

One instruction can be taken behind the executing one (spec p.535). Its
IF1 sets `PQ_W2`, its word 2 `PQ_CAPT` or `PQ_READY`, its operand words
fill `buf_q` (free: the executing instruction is in the Data Processor;
its own bus operand moves to row 10 the clock after the queued IF1, ahead
of a pending FOP2, and its unpack and FOP1 read it there, as at a slow
CLK.D the unpack may come after the queued words). It
starts (`promote`) on the first CLK.I rise with the Interface Processor
idle and the Data Processor done, in that same master clock; PC1 takes
PC2. A Data Processor operation gets `dp_start` the next master clock
(`pstart_q`), or, promoted in the done clock, the one after (`pwait_q`),
its first read from `sf_q`, as a held IF1 queued with it takes `p_sf`:
the read register holds FOP1's operand through done, and the operand bus
carries FOP1 the clock after. A promoted FLDCTL of FOP1 or FOP2 reads its
row in the promote clock.

Start fields (kind, precision, rounding, store form) have two owners.
The executing operation's are `kind_q` and its peers, which follow the
decode until it takes them: through its operand words, and from a
promotion to its start. A queued operation's are `p_kind` and its peers,
taken at its `p_load`. The Data Processor gets the executing one's while
it owns them, else a queued operation's, else the decode, so either
instruction can be decoded while the other waits to start. The rounding
mode is USER as that clock leaves it: a list op, FLDCTL, or one promoted
in the clock counts. SC.U is set after a promoted FLDCTL SC writes SC,
for a held IF1 run with it. In a done clock the Data Processor's flags go into
FFLAGS before a promoted instruction's.

/BSY is Low for:

| term | condition |
|---|---|
| `bsy_dp`, No Overlap | `IP_DPWAIT`: the instruction is in the Data Processor |
| `bsy_dp`, Intermediate (SC.OVRLP = 10) | `PQ_READY`: a queued instruction and its operands are complete |
| `store_wait`, both modes | an outbound instruction in `IP_DPWAIT`, a queued outbound one, or `fop_wait` |

The pin is a flop, `bsy_q`, loaded with these terms taken on the
registers' next values (`bsy_d`): each edge lands in the master clock it
would combinationally, and a board STOP flop fed from /BSY follows it
exactly one master clock later.

In No Overlap the queue still holds an IF1 the CPU fetched before STOP
took effect.

STOP is sampled before IF1 and, with EPA, before word 2 (Jan83 TM 9.6.4);
found Low, the fetch still completes and the refresh stream follows. So
with `PQ_READY` the next IF1, and its word 2 if STOP was first Low before
that, reach the bus (spec p.535: Intermediate "attempts to stop the CPU
after a second floating point instruction is transferred"; p.543: no
overrun of the queue). The IF1 is held: template and word 1 into `tpl_q`
and `w1_q` (the queued one keeps `p_fcw`), the address in `hold_pc_q`, a
word 2 in `hold_w2_q`. At
`promote` it runs at once (PC1) if the promoted one completed in that
clock, else it is queued (PC2) and the promoted operation's bus operand
moves to row 10, from its start clock on. Queued, a kept word 2 is taken
then (`h_load`, `PQ_CAPT` or `PQ_READY`). Run, a kept word 2 is taken
then too (`IP_OPERAND`, `IP_RESULT`) unless it starts the Data Processor
or is a list op (whose list would meet the promoted one's): those wait in
`IP_WORD2` for `rp_go`, a clock or two later, `rp_bsy` giving /BSY its
level once taken; the start then still meets the next CLK.D rise. An
IF1 or word 2 whose /DS rise falls in the `promote` clock is taken with
it. A queued instruction's operand word that comes before row 10 holds
the promoted operation's bus operand waits in `capk_q`.
An arithmetic trap flushes the queue and a held IF1 (p.558); PC2 keeps
the address.
/ABORT, as a level, forces both sequencers idle before the cycle is
seen; a running Data Processor operation finishes and its result is
dropped.

### 4.4 Multiply (FMUL, FPWR2): 28/42/48 clocks

| clock | word | action |
|---|---|---|
| 1-4 | UNP_A..UNP_BR | read A and B; classify; renormalize each (LZC, left shift, exponent - count); DE on a denormal |
| 5 | MUL_SP | `MSPC`: NaN, 0 x inf, inf, zero -> result and flags, jump to TAIL (7 clocks total) |
| 6 | MUL_EX | `MEXP`: exponent ea + eb; sign; S = M << 1 |
| 7 | MUL_3M | `M3`: X = 2M + M; B >> dropped bits (rest to `stin_q`); exponent - bias; S = 0; `cnt_q` = floor(nS/2) - 1 |
| 8.. | MUL_IT | `MSTP` x floor(nS/2) (12/26/32): S = (S + {0, M, 2M, 3M by B[1:0]}) >> 2; the two bits shifted out enter B from the top |
| +1 | MUL_PR | `PRD`: product into S, guard/round/sticky from B |
| +1 | ADD_CY | carry: S >> 1, exponent + 1 |
| +5 | ADD_LZ..ADD_RG | LZC, normalize, denormalize if tiny, round to precision, range (overflow, underflow, storage form) |
| +2 | TAIL, TAIL_WB | result latch; `done` |

16 + floor(nS/2): the published 28/42/48 (spec p.532).

### 4.5 Divide (FDIV, FRDIV): 29/43/49 clocks

| clock | word | action |
|---|---|---|
| 1-4 | unpack | FRDIV swaps which operand is A (`opnd_sw`) |
| 5 | DIV_SP | `DSPC`: NaN, 0/0, inf/inf, inf, zero divisor (DZ) |
| 6 | DIV_EX | `DEXP`: ea - eb; sign |
| 7 | DIV_LD | `DLD`: exponent + bias + precision offset; S = dividend >> 2 or 3; X = QM = 0; `cnt_q` = floor(nS/2) + 1 |
| 8.. | DIV_IT | `DSTP` x (floor(nS/2) + 2): digit from the table; S = 4S -/+ {D, 2D}; X or QM shifts the digit in |
| +1 | DIV_QS | `QSEL`: S = X - QM, less one if the remainder is negative; sticky from the remainder |
| +5 | ADD_LZ..ADD_RG | as the multiply |
| +2 | TAIL, TAIL_WB | |

17 + floor(nS/2): the published 29/43/49. The remainder routines reuse
`DSTP` with a batch length (`RLEN`) and a correction clock (`CORR`); the
BCD store reuses it to divide by 10^19.

### 4.6 Square root (FSQR): 37/66/77 clocks

| clock | word | action |
|---|---|---|
| 1-2 | UNP_B, UNP_BR | one operand |
| 3 | SQR_SP | `SSPC`: NaN, zero, negative (INV, reason 5), infinity |
| 4 | SQR_EX | `SEXP`: exponent halved, parity to `par_q` |
| 5 | SQR_LD | `SLD`: radicand fraction to A; first root bit; `cnt_q` = nS - 1 |
| 6.. | SQR_IT | `SSTP` x nS: non-restoring, one root bit a clock: S = 4S + next radicand pair - (4 root + 1), or + (4 root + 3) after a negative remainder; root bit into B; A << 2 |
| +1 | SQR_RS | `SRES`: root to S, sticky from the remainder and the radicand left |
| +5, +2 | ADD_LZ..ADD_RG, TAIL | |

13 + nS. This total is not published.

### 4.7 Exceptions, traps, acknowledge

| source | SC.IR | raised |
|---|---|---|
| a Data Processor flag with its USER trap enable set | 00 | at `fold` |
| no template, no table row, impossible word count | 01 | IF1 or word 2 /DS rise |
| another EPU's ID with its SC.EPUIDS bit set | 10 | IF1 /DS rise |
| FLDCTL into SC with N/S High at its last transfer | 11 | last word (write dropped) |

`raise` sets SC.IR and SC.IP. /INT is Low while SC.IP and SC.MIE are
set (p.534: IP indicates a pending interrupt), so software clearing IP
withdraws the request.

Acknowledge: the status SC.INTACK selects (0X: 0101, 10: 0110, 11:
0111). It is this EPU's if it requests with IEI High at the /DS fall
(p.556: when RD falls); `ack_q` holds that decision to the /DS rise, so
a trap raised or an SC write landing while /DS is Low changes neither
the vector, IEO nor IUS.

```
/AS  -_-----------------------
/DS  ----------______________-
IEO  ---_____________________... (Low from the /AS rise while requesting; stays Low once IUS is set)
AD7-0          <vector>          (SC 7:0, shifted left one if SV; not driven if NV)
                             ^ /DS rise: IUS set, IP and the request cleared
```

IEO = IEI and not (IUS or DLC or this EPU's acknowledge). The vector is
driven only with IEI High.

## 5. Timing and resources

External timing has two parts:

| part | clocks | origin |
|---|---|---|
| bus transfers | the CPU's own machine cycles; the Interface Processor adds none | strobe edges |
| computation | CLK.D rises from `start` to `done` | microprogram length |

Data Processor clocks, single/double/extended (the full table, with the
short paths, is in [K8070_FPU_TESTS.md](../K8070_FPU_TESTS.md)):

| operation | clocks | published (spec p.532) |
|---|---|---|
| add, subtract, load | 18 | yes |
| multiply | 28/42/48 | yes |
| divide | 29/43/49 | yes |
| square root | 37/66/77 | no |
| remainder, full batch | 29/43/49 | no |

Fit ([STATUS.md](../STATUS.md); Cyclone V 5CSEBA6U23I7, 48 MHz, slow
corner):

| unit | ALMs | Fmax | setup slack at 48 MHz |
|---|---|---|---|
| Data Processor alone | 1,958 | 52.8 MHz | 1.89 ns |
| whole chip | 2,633 | 54.8 MHz (median of 3 seeds) | 1.36-2.64 ns |

The register file is one MLAB; no M10K, no DSP. Critical path: the
microprogram counter through the ROM and the
operand selects into the working significand `s_sig`. The measures that
keep it there: the idle Data Processor holds the next operation and its
entry address, so a start's first word comes from the ROM at `upc_q`; the denormalize amount is formed at NORM so DNRM shifts by a
register; the Interface Processor's decode and start fields are
registered a clock ahead.

## 6. Inferred and assumed

The chip is known only from the preliminary specification. The RTL
follows it where it speaks; elsewhere a choice is assumed and the
vectors carry it. Ledgers: the "Assumed" tables in
[K8070_FPU_TESTS.md](../K8070_FPU_TESTS.md) and the FPU rows of
[DECISIONS.md](../DECISIONS.md). In summary:

- **Encoding**: every word-2 operation code, the list-byte layout, the
  FLDCTL selects.
- **Clocks**: CLK.D's rise as the Data Processor's step; the split of
  every routine into clocks (published totals included); every
  unpublished total and short path. `z8070_dp_ucode.txt` tags each
  routine `published` or `guess`.
- **Interface**: zero Interface Processor latency; /BSY as the store
  wait; the Intermediate /BSY condition; the store drive window; 00 on
  AD15-8 for byte drives; the PC1/PC2 format; which exceptions flush the
  queue; an invalid word 2 raised in program order; the IEO window; the
  acknowledge decided at the /DS fall.
- **Registers**: F0-F7 and FOP1/FOP2 not cleared by /RESET; the FOP1 and
  FOP2 contents for conversions and stores; FFLAGS FOP exponent bits; SC
  VIS ignored.
- **Results**: out-of-range integer and BCD stores; the multiply's
  handling of multiplier bits below the precision.
